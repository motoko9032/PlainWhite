\section{PWA 应用支持}

本网站已内置渐进式 Web 应用（PWA）基础能力：可安装到设备主屏幕，并在离线状态下继续浏览已缓存的页面。基础设施包括根目录的 \verb|manifest.webmanifest|（应用清单）、\verb|sw.js|（Service Worker 离线缓存）与 \verb|offline.html|（离线兜底页），应用图标与生成脚本位于 \verb|pwa/| 目录，完整的交接文档见 \verb|pwa/README.md|。

\subsection{运行平台、字体与导航}

普通浏览器页面与安装后的 standalone PWA 是不同运行环境，字体、导航和布局必须按平台隔离。各平台的维护位置与验证说明见 \verb|pwa/README.md|。

\begin{itemize}
	\item{普通桌面与移动浏览器继续使用网站导航和网页样式。界面字体由 Google Fonts 提供的 Noto Sans SC 为主；普通网页的首发文章阅读页才使用 EB Garamond 与 Noto Serif SC 衬线排版。字体加载非阻塞，Google Fonts 不可用或超时后由 CSS 系统字体栈回退。仓库 \verb|fonts/| 中的本地 TTF 仅作归档，不得加入页面加载流程。}
	\item{只有检测到 standalone 安装模式，页面才设置安装态与平台标记；\verb|data-app| 区分 iOS、Android 和桌面，\verb|data-os| 标记具体操作系统。普通浏览器不得创建安装态导航或套用安装态字体。}
	\item{iOS standalone 只使用 Apple 系统 UI 字体。字体加载器必须在插入 Google Fonts 样式表之前跳过字体请求；不得通过全局规则、Noto、衬线字体或桌面字体栈覆盖 iOS 字体。普通 Safari 网页不属于此限制，仍使用网页字体规则。}
	\item{iOS standalone 使用应用式多页面路由：顶层目的地为首页、公告、阅读、下载和更多；更多目录包含关于、特别文章、分发方式、支持、致谢、联系与投稿等子页。路由使用 \verb|#app/<route>|，路由变化时应同步当前页面、标题、\verb|aria-current|、应用内返回及浏览器历史状态。iPhone 使用底部应用导航，宽屏触控设备可使用顶部导航；不得将 Android 或桌面导航行为套用到 iOS。}
	\item{iOS 样式是受 Apple HIG 启发的 Web 实现，不是 UIKit 原生控件或官方合规认证。使用 \verb|viewport-fit=cover| 与 CSS \verb|env()| 安全区 inset 避让系统区域；顶部 inset 只计入一次，底部导航与正文留白不得遮挡内容。触控目标至少 44 CSS px，并尊重降低透明度、深色模式、文字放大、键盘焦点和 VoiceOver。}
	\item{Android standalone 使用独立的平台样式作用域，界面字体为 \verb|system-ui, Roboto|，中文使用系统 CJK 回退；不得使用 Noto Serif SC、EB Garamond 或 Apple UI 字体。导航采用 Material 3 Expressive 启发的 64 CSS px 顶部应用栏与 80 CSS px 全宽底部导航栏；底部目的地仍以首页、公告、阅读、下载、关于等站内锚点工作，并随页面滚动更新当前项，不得改成 iOS 的 \verb|#app/| 路由。}
	\item{Android standalone 必须通过 CSS 安全区 inset 避让状态栏、手势导航栏和显示切口；正文需留出底部导航栏高度，横向内容也要避让安全区。触控目标至少 48 CSS px；M3 颜色角色、状态层、深色模式与降低动态效果偏好应保持一致。固定低饱和主题色是 Web 端方案，不能宣称等同 Android Monet 动态取色。详细实现与检查项见 \verb|pwa/android-ui-guide.md|。}
	\item{桌面 standalone（macOS、Windows、Linux）不显示移动端底部导航，保留桌面顶部导航和可缩窄窗口使用的汉堡菜单；内容区最大宽度为 64rem，并按窗口安全区留出边距。字体按 \verb|data-os| 选择：macOS 使用本机系统 UI 字体及 PingFang SC 中文回退；Windows 使用 Segoe UI / Segoe UI Variable 与 Microsoft YaHei 回退，字体栈不得优先查找 PingFang；Linux 使用系统 UI 字体并提供 Noto Sans CJK SC 等中文回退。}
	\item{桌面和移动网页、三类 standalone 的 CSS 规则必须以平台属性明确限定，不能通过全局字体或组件规则覆盖其他平台。所有环境都应保留语义化结构、可见键盘焦点、足够对比度、文字缩放和 \verb|prefers-reduced-motion| 支持。CSS 材质和动效只能作为 Web 近似；修改平台导航或安全区后须按对应设备重新验证，不得将浏览器模拟结果表述为真机或官方合规认证。}
\end{itemize}

\subsection{维护与发布规则}

{\heiti 维护人员必须遵守以下规则：}

\begin{itemize}
	\item{\verb|sw.js| 必须始终位于站点根目录，其作用域覆盖整个站点，不得移动；}
	\item{每次发布静态资源变更（HTML、CSS、JavaScript、公告或文章数据、生成的HTML等）后，必须递增 \verb|sw.js| 顶部的 \verb|CACHE_VERSION| 版本号，否则用户会持续看到旧内容；}
	\item{\verb|PRECACHE_URLS| 只放首页必需的小型核心资源。普通网页的 Google Fonts 样式包装文件 \verb|style/fonts-google.css| 可加入预缓存；其中跨域字体文件不由本站 Service Worker 缓存，本地 \verb|fonts/*.ttf| 不得被页面请求或加入缓存。离线时使用 CSS 系统回退字体；\verb|offline.html| 必须保持自包含，不引用外部 CSS、JavaScript 或字体。}
	\item{\verb|files/| 目录中的大文件（PDF、EPUB）不缓存：体积大，且 PDF 阅读器按 Range 分段读取，缓存整份响应会导致读取错乱；首发文章页面采用导航网络优先，文章封面与其他大图片不得加入 \verb|PRECACHE_URLS|。}
	\item{新增 HTML 页面时，必须照抄现有同级页面 \verb|<head>| 中的 PWA 区块（manifest、图标、主题色等标签），并按页面所在目录层级调整相对路径前缀（根目录页面用 \verb|./|，一级子目录页面用 \verb|../|，二级子目录页面用 \verb|../../|）；}
	\item{每个页面的 \verb|viewport| meta 必须含 \verb|viewport-fit=cover|；新增页面时，必须复制浅色与深色两条带 \verb|media| 属性的 \verb|theme-color| 声明。}
	\item{更换品牌图标时，只修改 \verb|pwa/icon.svg|，并运行 \verb|python3 pwa/generate-icons.py| 重新生成全部 PNG 图标——脚本会解析 SVG 矢量并按要求加粗描边，无需手工编辑任何 PNG。当前正式图标为手写「纯白」字标（仅描边）。}
	\item{iOS 添加到主屏的图标必须是无透明通道（无 alpha）的 PNG，\verb|apple-touch-icon.png| 与 \verb|apple-touch-icon-180x180.png| 由生成脚本输出为 RGB，并同步写一份到站点根目录（iOS 的整站 Web Clip 兜底位置）；iOS 的 \verb|<link rel="apple-touch-icon">| 不支持 \verb|data:| URI，\verb|pwa/apple-touch-icon.base64.txt| 仅作内联备用，不得放进 link 的 \verb|href|；\verb|sw.js| 对路径含 \verb|apple-touch-icon| 的请求一律直接放行，避免 Service Worker 干扰 iOS 抓取图标。}
\end{itemize}

\section{首发文章与静态页面生成}

首发文章源文件位于 \verb|article/|，使用一篇文章一个 Markdown 文件的方式维护。文章列表和阅读页由仓库根目录下的 \verb|tools/build_articles.py| 生成到 \verb|article/index.html| 与 \verb|article/posts/<slug>.html|。生成页是完整的静态 HTML，读者访问网站时不需要服务器端代码，也不依赖浏览器枚举目录或读取 Markdown。

\subsection{新增文章的流程}

\begin{enumerate}
	\item 在 \verb|article/| 中新增按编号命名的文件，例如 \verb|article-03.md|；文件必须以 \verb|---| 开始，并在第二个 \verb|---| 后写正文。
	\item 填写元数据：\verb|title|（标题）、\verb|date|（\verb|YYYY-MM-DD|）、\verb|column|（栏目键）和 \verb|summary|（摘要）；\verb|cover|（封面PNG路径）及 \verb|slug|（页面文件名）可选。字段值按单行 \verb|key: value| 书写，不需要 YAML 引号或列表语法。
	\item 封面路径以 \verb|article/| 为基准，例如 \verb|covers/article-03.png|。封面必须是有效PNG；正文图片使用 \verb|![替代文本](相对路径)|，文件放在 \verb|article/| 内。
	\item 在仓库根目录运行 \verb|python3 tools/build_articles.py|，成功后会更新文章索引并生成每篇文章的页面。可运行 \verb|python3 tools/test_articles.py| 执行生成器自测。
	\item 提交并部署 Markdown、所引用的图片、生成的文章索引与阅读页。静态托管不会运行本地 Python 命令，因此源文件变化后必须先生成并提交产物；部署静态资源更新时按 PWA 规则递增缓存版本。
\end{enumerate}

\subsection{栏目、排序与封面规则}

允许的 \verb|column| 值为 \verb|fiction|（小说）、\verb|poetry|（诗歌）、\verb|essay|（散文）、\verb|fanfic|（同人文学）、\verb|short-poems|（特别专栏-短诗）及 \verb|others|（其他）。索引按以上固定顺序显示有文章的栏目；栏目内按发布日期从新到旧排列，同日文章按源文件名升序排列。

每个栏目 Hero 题图取本栏目中按日期从新到旧排列后第一篇带有有效 PNG 封面的文章。日期相同则按文件名升序确定顺序。文章无有效封面时不显示破损图片，栏目没有任何有效封面时退回无图排版。Hero 图使用替代文本、响应式裁切及懒加载；文章页封面同时输出图片尺寸以减少布局跳动。

\subsection{校验、Markdown 与安全}

缺少标题、日期格式不符或日历日期无效、栏目键未知、slug 格式非法或重复、front-matter 缺失等属于致命错误：生成器以非零状态中止并给出对应文件名，不生成新页面。缺少摘要时从正文首段生成并警告；缺少封面、封面路径错误或文件不是PNG时警告并按无封面处理。未知元数据字段也会警告并忽略。

生成器支持标题、段落、加粗、斜体、行内代码、引用、无序与有序列表（含一层缩进嵌套）、链接、图片、围栏代码块和分隔线。它不支持完整 CommonMark/GFM 语法，例如表格、脚注与任务列表；遇到不支持的排版应使用普通段落或列表表达。

正文中的原始 HTML 会转义后作为文字显示，不会插入可执行节点。外部链接仅允许 \verb|http|、\verb|https| 与 \verb|mailto| 协议；不安全协议按纯文本处理并输出警告。正文图片必须使用 \verb|article/| 内真实存在的相对路径，路径不合规或文件缺失时显示文字占位并输出警告。

文章源文件须按 \verb|article-NN.md| 形式编号命名。\verb|README.md| 是维护文档，不作为文章读取；其他不符合命名规则的 Markdown 文件会被忽略并警告。

生成的文章页面目录完全由脚本管理：构建会覆盖列表页、重新生成当前文章页，并清理已无对应源文章的旧页面。不要在生成目录中手工保存文件。脚本可重复运行，输出顺序稳定。
