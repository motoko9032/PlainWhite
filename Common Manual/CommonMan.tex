\subsection{目录的含义}

以下是目录内各个文件夹的含义，上传文件、提交代码的时候{\heiti 必须}严格参考各个文件夹的语义：

{\kaishu \begin{itemize}
	\item{files – 网站文件（指用户需要下载的内容）}
	\item{style – 样式表文件夹（存储css样式表）}
	\item{script - JavaScript脚本文件夹（存储JavaScript脚本）}
	\item{announcements – 公告文件夹（存储首页公告的Markdown文件与回退数据，由\verb|script/announcements.js|动态渲染）}
	\item{sub – 公众号原文与LOFTER原文列表页文件夹（存储各期列表页、文章Markdown文件与回退数据，按\verb|WeChat|、\verb|LOFTER|、\verb|special-sub|三个子目录存放）}
	\item{fonts – 字体文件夹（存储网站本地字体文件）}
	\item{pwa – PWA支持文件夹（存储应用图标、图标生成脚本与PWA交接文档，详见\verb|pwa/README.md|）}
	\item{Common Manual – 通用手册文件夹（存储本手册的\LaTeX 项目文件）}
\end{itemize}}

\section{PWA 应用支持}

本网站已内置渐进式 Web 应用（PWA）基础能力：可安装到设备主屏幕，并在离线状态下继续浏览已缓存的页面。基础设施包括根目录的 \verb|manifest.webmanifest|（应用清单）、\verb|sw.js|（Service Worker 离线缓存）与 \verb|offline.html|（离线兜底页），应用图标与生成脚本位于 \verb|pwa/| 目录，完整的交接文档见 \verb|pwa/README.md|。

{\heiti 维护人员必须遵守以下规则：}

\begin{itemize}
	\item{\verb|sw.js| 必须始终位于站点根目录，其作用域覆盖整个站点，不得移动；}
	\item{每次发布静态资源变更（HTML、CSS、JavaScript、公告数据等）后，必须递增 \verb|sw.js| 顶部的 \verb|CACHE_VERSION| 版本号，否则用户会持续看到旧内容；}
	\item{\verb|files/| 目录中的大文件（PDF、EPUB）不缓存：体积大，且 PDF 阅读器按 Range 分段读取，缓存整份响应会导致读取错乱；}
	\item{新增 HTML 页面时，必须照抄现有同级页面 \verb|<head>| 中的 PWA 区块（manifest、图标、主题色等标签），并按页面所在目录层级调整相对路径前缀（根目录页面用 \verb|./|，二级目录页面用 \verb|../../|）；}
	\item{更换品牌图标时，只修改 \verb|pwa/icon.svg|，并运行 \verb|python3 pwa/generate-icons.py| 重新生成全部 PNG 图标——脚本会解析 SVG 矢量并按要求加粗描边，无需手工编辑任何 PNG。当前正式图标为手写「纯白」字标（仅描边）。}
	\item{iOS 添加到主屏的图标必须是无透明通道（无 alpha）的 PNG，\verb|apple-touch-icon.png| 与 \verb|apple-touch-icon-180x180.png| 由生成脚本输出为 RGB，并同步写一份到站点根目录（iOS 的整站 Web Clip 兜底位置）；iOS 的 \verb|<link rel="apple-touch-icon">| 不支持 \verb|data:| URI（base64 硬编码不可行），\verb|pwa/apple-touch-icon.base64.txt| 仅作内联备用，不要放进 link 的 href；\verb|sw.js| 对路径含 \verb|apple-touch-icon| 的请求一律直接放行，避免 Service Worker 的缓存策略干扰 iOS 添加主屏时的图标抓取。}
	\item{每个页面的 \verb|viewport| meta 必须含 \verb|viewport-fit=cover|，否则底部安全区 \verb|env(safe-area-inset-*)| 不生效，悬浮 Tab Bar 会被系统手势条遮挡；\verb|<head>| 中的 \verb|theme-color| 已按浅色/深色拆成两条（带 \verb|media| 属性），新增页面时两条都要复制。}
	\item{底部悬浮 Tab Bar 仅在「添加到主屏」的安装模式（standalone）显示：iOS 为高斯模糊玻璃态，Android 为低饱和紫罗兰紫（Material You 莫奈色）胶囊，均在底部并适配安全区；浏览器里访问不显示，保持原样。检测与注入逻辑在 \verb|script/script.js|，样式在 \verb|style/style.css|。}
	\item{深色模式跟随系统 \verb|prefers-color-scheme|，遵循 WCAG 对比度与无障碍标准（\verb|color-scheme|、焦点可见、\verb|prefers-reduced-motion|、\verb|prefers-contrast|）；新增颜色一律使用 \verb|style/style.css| 顶部的语义 CSS 变量，禁止写死新颜色。}
	\item{iOS 安装模式已按 Apple 规范适配：状态栏 \verb|black-translucent|（透明融入）、顶部 header 让出状态栏安全区、取消顶部汉堡菜单（由底部 Tab Bar 承担导航）；Android 端除底部 Tab Bar 外，其余适配待办登记在 \verb|pwa/android-ui-guide.md|，由后续接手者按 Material Design 3 规范推进。}
\end{itemize}
