# 公告目录

本目录集中存放首页公告区的公告文件。首页会自动读取这里的内容并渲染在公告区，读者无需跳转页面。

## 自动归档（历史公告）

首页公告区最多展示**最新 3 条**公告。当本目录中的公告累计**超过 3 条**时，多余陈旧公告会自动叠放到 [历史公告页](./history/)（`announcements/history/` 目录），并在首页公告区末尾追加「查看全部历史公告」入口，**无需移动文件或做任何额外操作**：

- 首页自动取编号最大的 3 条公告展示；
- 其余更早的公告自动显示在历史公告页，按时间顺序排列；
- 历史公告页自动读取本目录下的全部公告文件并排除最新 3 条，无需手动同步。

## 发布新公告（推荐方式，适合非专业编辑）

只需要两步：

1. 复制上一条公告文件（例如 `announcement-03.md`）；
2. 把文件名编号 **+1**（例如改成 `announcement-04.md`），然后改掉内容：

```markdown
---
date: 2026.11
title: 第四期发布
badge: 最新
---

第四期现已上线，可在下载区获取 PDF 与 EPUB 版本。
```

保存后，网站会自动按编号顺序读取，并把新公告追加在公告区；当公告超过 3 条时，最旧的公告会自动进入历史公告页。

### 字段说明

- 顶部三横线（`---`）之间是公告信息：
  - `date`：展示日期，如 `2026.10`（必填）
  - `title`：公告标题（必填）
  - `badge`：标题旁的小徽标（如 `最新`），不需要就留空（选填）
- 第二个 `---` 之后是公告正文，支持简单 Markdown：**加粗**、`行内代码`、[链接](https://example.com)，空行分段。

### 注意事项

- 文件名必须形如 `announcement-01.md`、`announcement-02.md`、`announcement-03.md`……，**编号必须连续**，页面按编号顺序读取，遇到断号会停止；
- 每个公告文件**必须以 `---` front-matter 开头**（照抄上面的模板即可），否则该文件会被忽略，视为公告结束；
- 若删除中间某条公告，请把后面的文件重新连续编号。

## 其他说明

- 网站部署或使用本地服务器（如 Live Server）访问时，自动读取上面的 Markdown 文件；
- 如果直接双击打开 `index.html`（`file://` 协议），浏览器禁止读取文件，此时会回退到 `data.js` 中的数据；两种方式内容应保持一致；
- 首页公告区最多展示最新 3 条，更早的公告自动归档到 [历史公告页](./history/)；`data.js` 是回退数据源，首页与历史公告页共用同一份数据，归档同样自动生效；
- 无需修改 `index.html`、`style/style.css` 或 `script/script.js`。
